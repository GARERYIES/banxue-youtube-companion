# 验证记录

## 已验证

在 macOS、Google Chrome、Node.js 24.19.0、OpenCLI MCP npm 0.0.27、Codex CLI 0.162.0-alpha.2 环境完成本地验证：

- 加载未打包扩展并固定到 Chrome 工具栏。
- 点击扩展连接一个已经播放到中途的公开 ROS2 教学视频，保留原播放位置。
- 本地服务关闭后，通过扩展和 native messaging 重新启动服务。
- 跟随真实视频播放读取字幕，生成两张新的中文学习卡片，生成耗时约 19 秒和 38 秒。
- 在界面保存卡片，在笔记页查看，在复习页揭示参考答案。
- 通过本地 MCP 读取课程、播放位置和已观看字幕。
- 11 项单元测试通过。可以运行 `npm test` 复现。
- 发布目录的 OpenCLI 包发现和只读连接通过；使用空白数据目录与独立端口启动服务，验证页面、扩展来源许可和 POST 会话校验。

README 中的图片是与侧栏共享界面的本地预览，不是 Chrome 工具栏或扩展加载状态截图。
